# Проверенные источники

Сверено 16 ноября 2026 года.

- Используются `LIST UPS`, `LIST VAR`, `STARTTLS`, `USERNAME` и `PASSWORD`. Старые серверы могут принимать имя и пароль для последующих привилегированных команд и оставлять чтение открытым. RustNUT передаёт пару только в проверенном TLS-сеансе и ограничивается чтением. Прямой TLS предназначен для туннеля или прокси. [Руководство разработчика NUT](https://networkupstools.org/docs/developer-guide.chunked/net-protocol.html)
- Интерфейс работает через Win32. Explorer владеет показом tray-уведомлений. Запрос локального выключения временно включает привилегию `SeShutdownPrivilege`. Штатное выключение использует `ExitWindowsEx(EWX_POWEROFF)`. Для выключения без подтверждения `InitiateShutdownW` получает флаги `SHUTDOWN_POWEROFF`, `SHUTDOWN_FORCE_SELF` и `SHUTDOWN_FORCE_OTHERS`. [Windows notification area](https://learn.microsoft.com/en-us/windows/win32/shell/notification-area), [ExitWindowsEx](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-exitwindowsex), [InitiateShutdownW](https://learn.microsoft.com/en-us/windows/win32/api/winreg/nf-winreg-initiateshutdownw)
- Импортируемый `GetDpiForWindow` задаёт минимальную версию Windows 10 1607. Windows 11 выпускается для 64-битных платформ. Для приложения проверяется PE x86, а на Windows x64 используется WOW64. [GetDpiForWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getdpiforwindow), [Windows 11 requirements](https://learn.microsoft.com/en-us/windows/whats-new/windows-11-requirements)
- WinNUT рассмотрен по описанию репозитория для сверки назначения и совместимости. Код, тексты, оформление и ресурсы не переносились. [WinNUT-Client](https://github.com/nutdotnet/WinNUT-Client)
- Под шкалой нагрузки используется измеренная активная мощность `ups.realpower` или `output.realpower`. При отсутствии обоих значений показывается «— Вт». [Справочник переменных NUT](https://networkupstools.org/docs/user-manual.chunked/_variables.html)
- Поддрайвер PowerCOM HID в NUT 2.8.4 исключает `battery.voltage` и `battery.voltage.nominal`, так как соответствующие HID-поля на POWERCOM дублируют выходное напряжение и его номинал. Проверенный сервер с PowerCOM HID 0.71 вернул `ERR VAR-NOT-SUPPORTED` на оба запроса. [Исходник поддрайвера PowerCOM](https://github.com/networkupstools/nut/blob/v2.8.4/drivers/powercom-hid.c#L368-L375)
