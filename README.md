# RustNUT

RustNUT — лёгкий клиент Network UPS Tools (NUT) для Windows, написанный на Rust. Он получает показания источника бесперебойного питания (ИБП) с NUT-сервера, следит за состоянием питания в фоне и по заданным условиям может выключить компьютер, перевести его в сон или гибернацию.

RustNUT работает со стандартным протоколом NUT и подходит для ИБП разных производителей. Для работы нужен доступный по сети NUT-сервер с настроенным ИБП. Набор показаний зависит от модели ИБП и драйвера на сервере.

## Возможности

- **Подключение.** Обычный TCP, STARTTLS и прямой TLS через туннель или прокси. Поддерживаются обнаружение ИБП, вход с учётными данными по TLS и автоматическое переподключение.
- **Панель мониторинга.** Шесть шкал показывают входное и выходное напряжение, частоту, заряд, нагрузку и напряжение батареи. Под нагрузкой отображается измеренная активная мощность в ваттах, если её передаёт сервер. В верхней панели видны состояние питания, остаток автономности в формате `ЧЧ:ММ:СС`, модель, производитель и серийный номер. Все полученные параметры доступны в таблице. Для недоступных показаний выводится «Нет данных».
- **Трей и уведомления.** Статус ИБП и заряд видны при наведении на значок. Windows может показать уведомления о потере связи с ИБП, переходе на батарею, низком заряде, возврате питания от сети, ожидании или ошибке действия питания. Язык уведомлений совпадает с языком интерфейса.
- **Действия питания.** Выключение, сон и гибернация текущего компьютера по порогам, по самому факту работы от батареи или по флагу `FSD` от сервера. Доступны настройка задержки и отмена действия до его запуска.
- **Настраиваемые диапазоны.** Выход показаний за заданные границы отмечается на панели мониторинга.
- **Интерфейс.** Русский и английский языки, светлая, тёмная и системная темы. Системная тема выбрана по умолчанию и следует режиму приложений Windows. Панель и таблица адаптируются к размеру окна. `F11` переключает полноэкранный режим, `Esc` позволяет из него выйти.
- **Portable и автозапуск.** Один нативный EXE, настройки рядом с ним, пароль защищён Windows DPAPI. Приложение можно запускать вместе с Windows сразу в трее.

## Запуск

Скачайте `RustNUT-windows-x86.zip` в разделе **Releases** на GitHub, распакуйте его в папку с правами записи и запустите `rustnut.exe`. Установка не требуется. 32-битный EXE работает в Windows 10 x86 версии 1607 и новее, а также в Windows 10/11 x64 через WOW64.

## Настройка подключения

1. Откройте **Настройки → Подключение**. Введите DNS-имя или IP-адрес NUT-сервера в поле **Адрес сервера**. Порт NUT по умолчанию — `3493`. Для туннеля укажите адрес и порт его точки входа.
2. В списке **Защита соединения** выберите режим, который поддерживает сервер.

   | Режим | Когда использовать |
   | --- | --- |
   | **Обычный TCP** | Для NUT-сервера в доверенной сети без TLS. |
   | **STARTTLS** | Если сам NUT-сервер поддерживает переход на TLS после подключения. |
   | **TLS-туннель** | Если TLS устанавливается сразу при подключении к туннелю или прокси. |

   В обоих режимах TLS RustNUT проверяет имя и цепочку сертификата средствами Windows. Используйте адрес, указанный в сертификате, и доверенный в Windows центр сертификации. Минимальная версия TLS — 1.2.

3. Если серверу нужны учётные данные, заполните **Имя пользователя** и **Пароль** в режиме TLS. При смене адреса, порта или имени пользователя введите пароль заново. Для удаления сохранённых данных нажмите **Очистить учётные данные** и сохраните настройки.
4. Укажите **Интервал опроса, с**. Допустимы значения от `2` до `60`, по умолчанию — `5`.
5. Если имя ИБП известно, введите его в поле **Имя ИБП**. Иначе сохраните подключение с пустым полем, дождитесь подключения, снова откройте настройки и нажмите **Выбрать…**. Если оставить поле пустым, RustNUT будет выбирать первый ИБП из списка сервера при каждом подключении.
6. Нажмите **Сохранить настройки** и проверьте, что на панели появились состояние питания и показания.

Если соединение не устанавливается, проверьте доступность порта с компьютера Windows командой `Test-NetConnection 192.168.1.50 -Port 3493`, подставив свой адрес и порт. Для проверки списка ИБП на самом NUT-сервере используйте `upsc -l localhost`. [Справка upsc](https://networkupstools.org/docs/man/upsc.html)

## Настройка действий питания

Автоматические действия выключены по умолчанию. Они выполняются средствами Windows на компьютере, где запущен RustNUT. Действия доступны при любом из трёх режимов подключения.

1. Закрепите конкретный ИБП в поле **Имя ИБП**.
2. Откройте **Настройки → Действия питания** и включите **Разрешить автоматические действия**.
3. В списке **Действие Windows** выберите **Выключение**, **Сон** или **Гибернация**.
4. Задайте условие запуска.

   | Условие | Как работает |
   | --- | --- |
   | **Выключать ПК при работе от батареи** | Реагирует на первое свежее показание работы от батареи, в том числе если ИБП уже на батарее в момент запуска RustNUT. Поля порогов блокируются. При выборе сна или гибернации подпись чекбокса меняется. |
   | **Пороги** | Во время работы от батареи достаточно любого включённого условия. Заряд или остаток автономности достигает заданного значения или опускается ниже него, либо время на батарее достигает заданной длительности. `0` отключает соответствующий порог. По умолчанию задан только порог заряда в 15 %. |
   | **Реагировать на сигнал FSD сервера** | Добавляет отдельное условие по флагу принудительного выключения, полученному от выбранного NUT-сервера. |

5. Установите **Задержку предупреждения**. По умолчанию она составляет `30` секунд. При необходимости включите **Добавить дополнительную задержку**. Опция **Выполнять без отсчёта** пропускает обе задержки. Действие выполняется по свежим показаниям при опросе.
6. При необходимости выберите **Выключать без подтверждения**. В этом режиме Windows принудительно закрывает приложения во всех сеансах этого ПК, поэтому несохранённые данные могут потеряться. При обычном выключении приложение с несохранёнными данными может задержать завершение работы. [Как Windows обрабатывает принудительное выключение](https://learn.microsoft.com/windows/win32/api/winreg/nf-winreg-initiateshutdownw)
7. Нажмите **Сохранить настройки** и подтвердите автоматическое действие в диалоге RustNUT.

Для выключения **сразу при переходе на батарею** выберите действие **Выключение** и отметьте **Выключать ПК при работе от батареи** и **Выполнять без отсчёта**. RustNUT запросит выключение при ближайшем опросе, который покажет работу от батареи.

Если условие исчезнет или связь с ИБП прервётся, отсчёт будет отменён. Его также можно остановить командой **Отменить действие** в окне или в меню трея. После ручной отмены RustNUT снова разрешит срабатывание, когда ИБП вернётся к питанию от сети без флага `FSD`.

## Настройка диапазонов

Откройте **Настройки → Диапазоны**, включите **Включить ограничения** и задайте минимум и максимум для нужных показаний. Эти параметры служат для подсветки отклонений на панели мониторинга. Условия автоматического выключения настраиваются отдельно во вкладке **Действия питания**.

| Параметр | Диапазон по умолчанию |
| --- | --- |
| Входное и выходное напряжение | 90–264 В |
| Частота на входе | 45–65 Гц |
| Напряжение батареи | 9–60 В |
| Нагрузка ИБП | 0–100 % |

Если для частоты оставлен исходный диапазон, выбор номинала **50 Hz** или **60 Hz** задаёт допуск ±5 Гц. Указанный вручную диапазон частоты имеет приоритет. При отключении ограничений значения полей сохраняются.

Шкалы входного и выходного напряжения рассчитаны на 0–270 В, шкала напряжения батареи — на 6–20 В. Числовое показание остаётся фактическим, даже если указатель достигает края шкалы.

## Работа в фоне и перенос настроек

- В разделе **Настройки → Подключение → Приложение** выберите **Язык** и **Тему**, а также настройте **Показывать уведомления**. Отображение уведомлений зависит и от настроек Windows.
- Закройте или сверните окно, чтобы оставить RustNUT в трее. Через контекстное меню значка можно открыть обзор или настройки. Команда **Выход** останавливает мониторинг.
- Чтобы запускать мониторинг при входе в Windows, откройте **Настройки → Подключение**, включите **Запускать с Windows** и сохраните. Укажите ключ `--background`, если хотите запустить EXE из командной строки сразу в трее.
- Настройки хранятся в файле `settings.json` рядом с запущенным EXE. Для переноса скопируйте оба файла. В другом профиле Windows может потребоваться заново ввести пароль. Если переместили EXE с настроенным автозапуском, выключите и снова включите автозапуск, чтобы обновить путь.
- Кнопка **Сбросить настройки…** после подтверждения удаляет локальный файл и отключает автозапуск RustNUT.

## Сборка из исходников

Понадобятся Rust stable, MSVC Build Tools с компонентами C++ x86/x64 и Windows SDK. Выполните в PowerShell из корня проекта.

```powershell
rustup target add i686-pc-windows-msvc
cargo fmt --check
cargo clippy --locked --all-targets --target i686-pc-windows-msvc -- -D warnings
cargo test --locked --target i686-pc-windows-msvc
./scripts/package.ps1 -Build
```

Пакет, EXE и контрольные суммы появятся в `dist/`. [Проверки и совместимость](docs/verification.md) · [Спецификация протокола NUT](https://networkupstools.org/docs/developer-guide.chunked/net-protocol.html)

## English quick start

Extract the Windows x86 ZIP from **Releases** and run `rustnut.exe`. Open **Settings → Connection**, enter your NUT server and port, then select **Plain TCP**, **STARTTLS**, or **TLS tunnel** as appropriate. Credentials require TLS. Save to discover UPS devices, then use **Discover…** to pin one. A named UPS is required for **Power actions**. RustNUT runs in the system tray and stores `settings.json` beside the EXE.
